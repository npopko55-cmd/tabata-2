# DESIGN_DIFF — сравнение оригинала и моей версии

**Оригинал:** https://walk-walk.ru/programs/tabata (Tilda)
**Моя версия:** http://127.0.0.1:5173 (HTML/CSS, файлы: `index.html`, `styles.css`)

Сравнение выполнено сверкой реальных Tilda-стилей (inline-CSS внутри оригинального HTML) и `preview_inspect` моей версии. Точные числовые значения — из CSS оригинала. Размеры/цвета приведены так, как они **на самом деле** в исходнике, а не «по описанию».

## Палитра оригинала (подтверждённые hex)

## Секция 1. Header (шапка)

**Что одинаково:**
- Светлый фон (у меня `#f5f5f5`, у оригинала тоже светлый)
- CTA «Выбрать абонемент» — красный фон `#ce2c01`, белый текст, pill-форма
- «Личный кабинет» — outline кнопка

**Что отличается:**
- У меня бургер виден на 1280px (медиа `max-width:1024` для скрытия) — должен быть **только на мобильных** (примерно ≤959px по Tilda брейкпойнтам). У оригинала на desktop бургера нет.
- Кнопка «Выбрать абонемент» оригинала — **width 195px, height 45px, font-size 16px, border-radius 30px**. У меня `.btn--sm`: padding 10/18, font-size 14px — кнопка получается уже и ниже.

**Правки CSS:**
```css
/* styles.css */
.header__burger { display: none; }
@media (max-width: 959px) {
  .header__burger { display: flex; }
  .header__nav { display: none; }
}
/* убрать дублирующий media (max-width:1024) для .header__burger */

.header__actions .btn--sm {
  padding: 12px 22px;
  font-size: 16px;       /* было 14px */
  min-width: 180px;
  height: 45px;
}
```

## Секция 2. Hero

**Что одинаково:**
- Красная карточка слева `#ce2c01`, фото справа
- Метрики 2×2 (4 шт), иконки слева от чисел, текст белый

**Что отличается:**
- **Заголовок «Шагательная табата»**: у меня крупный с белой плашкой «2.0». В оригинале нет «2.0» в заголовке (это страница `/tabata`, не `/tabata-2`). Но плашка «2.0» сама по себе — нормальное решение. Только **уменьши её паддинги** — сейчас в моей версии она крупная и «съедает» центр заголовка.
- **Скругление красной карточки:** оригинал **10px**, у меня `--radius-sm = 10px` — OK. Но `.hero__card` использует `var(--radius-sm)` = 10px — это совпадает. Проверь, что не наследует более крупный. По факту совпадает.
- **Кнопка «Начать тренироваться»**: у меня белый фон + красный текст + pill + 18px. В оригинале — **белый фон, тёмный текст `#1f1300`, font-family Inter, font-size 14px, border-radius 30px, height 56px** (на hover становится красная заливка с белым текстом).
- **Хлебные крошки**: у меня opacity 0.85, у оригинала text лёгкий, тоже белый — близко. ОК.
- **Wave pattern**: у меня `background-image` на самой карточке c `background-blend-mode: soft-light` — в реальности волны почти не видны. В оригинале волна — это **отдельный абсолютный div с фоновой картинкой**, наложенный с opacity. Визуально у меня волн нет, у оригинала они угадываются справа.

**Правки CSS:**
```css
.btn--white {                          /* кнопка hero */
  background: #fff;
  color: #1f1300;                      /* было: color: var(--color-primary) — красный */
  font-family: var(--font-b);          /* Inter, не Unbounded */
  font-weight: 400;                    /* было 500 */
}
.btn--lg {
  font-size: 14px;                     /* было 18px — это для hero-кнопки */
  padding: 18px 36px;                  /* высота ~56px */
  border-radius: 30px;                 /* убедиться, что pill */
}
.hero__card {
  background-blend-mode: normal;       /* убрать soft-light — волны не читаются */
  background-size: 60%;
  background-position: right -40px bottom -40px;
  opacity: 1;                          /* паттерн нужен с прозрачностью */
}
/* лучше: вынести wave в ::after с opacity */
.hero__card::after {
  content: "";
  position: absolute; right: 0; bottom: 0;
  width: 55%; height: 60%;
  background: url('https://static.tildacdn.com/tild3562-3535-4166-b634-663130393766/SVG.png') no-repeat right bottom / contain;
  opacity: 0.22;
  pointer-events: none;
}
.hero__card { position: relative; overflow: hidden; }
.hero__title-accent {
  padding: 0 12px;                     /* было 2px 14px — уменьшить вертикалку */
  font-size: 0.7em;                    /* плашка должна быть мельче основного слова */
  vertical-align: 0.15em;
}
```

## Секция 3. «О программе»

- **Кнопка «Начать тренироваться»** под секцией — у меня сейчас `.btn--primary` (красный). В оригинале — **белая (`#fff`) с тёмным текстом и красной обводкой 1px**, как и кнопка в hero. Это пара одинаковых кнопок: в hero и под about.

- **«+ ещё 12/16 тренировок»** — у меня pill-плашка `#f5f5f5`. В оригинале — текст 14px на красном pill-фоне? Проверь: судя по структуре, в оригинале это просто красный pill (как кнопка-метка).

**Правки CSS:**

}
.about__cta .btn--primary:hover {
  background: var(--color-primary);
  color: #fff;
}

.about__counters span {
  background: var(--color-primary);    /* красный pill, не серый */

## Секция 7. Прайс (3 тарифа)

Здесь самые серьёзные расхождения.

**Что одинаково:**
- 3 карточки в ряд, центральная — featured с красной заливкой и таймером, у каждой бейдж скидки и кнопки

**Что отличается (КРИТИЧНО):**

1. **Бейдж «Скидка X%»** — у меня жёлтый pill (`#ffb600` фон, тёмный текст, 13px / weight 600). В оригинале — **красный pill** (`#ce2c01` фон, **белый текст**, **12px / weight 400**, **width 100px / height 30px**).

2. **Цена «2 990 ₽»** — у меня **38px / weight 700**. В оригинале **18px / weight 400, Unbounded**. У меня цена визуально в 2 раза крупнее, чем должна быть.

3. **Старая цена «9 190 ₽»** — у меня 15px, серая, зачёркнутая. В оригинале примерно так же, но цвет может быть конкретный muted-red — у тебя ок.

4. **Кнопка «Оформить абонемент»** — у меня pill (999px). В оригинале **border-radius 30px** при height 48px — практически то же. ОК.

5. **Кнопка «Купить в подарок»** — у меня outline с **тёмной (`var(--color-text)`) обводкой**. В оригинале **обводка красная `#cf2c02`**, текст тёмный `#1f1300`. Это важно — outline-кнопка должна быть «красной с прозрачной заливкой», не «чёрной».

6. **Featured-карточка (центр)**:
   - У меня `transform: scale(1.02)` — слегка крупнее. В оригинале **выделяется не масштабом, а только цветом фона** (красным).
   - Таймер: у меня тёмный `#1f1300` фон. В оригинале таймер тоже тёмный — близко.
   - Радиус карточки: у меня `--radius-lg = 24px`. В оригинале **15px** (на основе паттерна) или **10px**. Слишком сильно округлено у меня.

7. **Иконки features (галочки)** — у меня `::before` контент "✓" в `.rate-card__features li::before`. В оригинале это **SVG-иконки галочек в красном круге** (или цветные галки). Псевдо-элемент «✓» выглядит грубее.

8. **`rate-card__monthly` («698 ₽ в месяц»)** — у меня opacity 0.7 и 13px. В оригинале **выделена сильнее** — например, тёмная плашка или просто крупнее.

.rate-card { border-radius: 15px; }    /* было 24px */

.rate-card__discount {
  background: var(--color-primary);    /* было var(--color-primary-hover) жёлтый */
  color: #fff;
  font-size: 12px;                     /* было 13px */
  font-weight: 400;                    /* было 600 */

  font-size: 38px;                     /* МОЖНО ОСТАВИТЬ как маркетинговый акцент,

  /* В чистом «как в оригинале»: font-size: 28px; font-weight: 500; */
