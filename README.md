# Шагательная Табата 2.0 — landing

Standalone-копия лендинга `walk-walk.ru/programs/tabata`, переписанная как чистый HTML+CSS+JS без Tilda. Сделана как **шаблон**: для каждого следующего запуска (новой Табаты, Антисутулости, Острова стройности и т.д.) копируешь папку, правишь контент в нескольких местах — получаешь новый ленд за 15–30 минут.

## Структура папки

```
landings/tabata-2/
├── index.html      ← разметка ленда (всё что видно на странице)
├── styles.css      ← все стили (палитра, шрифты, сетки, адаптив)
├── script.js       ← countdown, бургер, слайдер отзывов, попап, sticky, back-to-top
├── server.js       ← локальный preview-сервер (node server.js)
├── SOURCE_MAP.md   ← карта оригинального ленда Tilda (для справки)
├── .claude/        ← конфиг preview-сервера для Claude Code
└── README.md       ← этот файл
```

## Как сделать новый ленд под другой запуск

**Шаг 1.** Скопируй всю папку:
```bash
cp -r landings/tabata-2 landings/antisutulost
```

**Шаг 2.** Обнови **content-точки** ниже. Все они помечены комментариями в коде — `Ctrl+F` тебе в помощь.

### Что менять в `index.html`

| Где (CSS-якорь) | Что менять |
|---|---|
| `<title>`, `<meta name="description">`, `og:title`, `og:url`, `<link rel="canonical">` | SEO/превью в соцсетях. **Поменяй на новый адрес и название** |
| `.hero__title` | Главный H1: «Шагательная табата 2.0» → новое название курса |
| `.breadcrumbs` | Хлебные крошки (последний `<span>`) |
| `.hero__stats` | 4 метрики курса: количество тренировок, длительность, шаги, темп |
| `.about__text p` | Описание программы (2 абзаца) |
| `.about__video-wrap` `style="background-image:..."` | URL превью видео |
| `.about__features` | 4 преимущества (текст + URL фото) |
| `.about__screens img` | 5 скриншотов уроков |
| `.about__counters span` | «+ ещё 12 тренировок» и т.п. |
| `.benefits__list li` | Список «Что вас ждёт» (6 плюсов + 1 минус) |
| `.benefits__photo` | Фото справа от списка |
| **Секция `.updates`** | **3 карточки с обновлениями версии 2.0** (заголовок + описание). Это новый блок относительно оригинала — здесь рассказывай, что нового в этом запуске |
| `.review-card` | Карточки отзывов (имя, аватар, текст). Сейчас 10 штук, можно добавить/убрать |
| `.rates-banner h2` | «Скидка 70%» — заголовок над прайсом |
| `.rate-card` | 3 тарифа: название, скидка, цены, фичи, ссылки оплаты (`/2-months`, `/6-months`, `/all`). Сделай find&replace для своих маршрутов |
| `.help__buttons a` | Ссылки WA и MAX для контакта |
| `.footer__phones`, `.footer__col--legal` | Телефоны, юр. инфо, соцсети, ссылки на политику |

### Что менять в `script.js`

```js
const CONFIG = {
  countdownDeadline: '2026-06-30T23:59:59+03:00'  // ← дата окончания акции
};
```

Меняешь одну строку → таймер на центральном тарифе крутится до этой даты. Если до даты больше суток — показывается «Д : Ч : М : С», меньше — только «Ч : М : С».

### Что менять в `styles.css`

Палитра вверху файла, в `:root`:

```css
:root {
  --color-primary: #ce2c01;       /* основной красный (бренд ШД) */
  --color-primary-hover: #ffb600; /* акцент/hover */
  --color-soft: #f5f5f5;          /* фон карточек */
  --color-dark: #1f1300;          /* футер, заголовки */
  --font-h: 'Unbounded', ...;     /* шрифт заголовков */
  --font-b: 'Inter', ...;         /* основной шрифт */
}
```

Меняешь 5 переменных — меняется цветовая схема всего ленда. Если делаешь, например, «Остров стройности» в зелёных тонах — здесь это правится.

### Картинки

Все картинки сейчас — прямые ссылки на `https://static.tildacdn.com/...` из оригинального ленда. Это работает, грузится быстро, ничего не нужно перезаливать.

Если хочешь заменить картинки на свои:
1. Загрузи фото на любой CDN (Cloudflare R2, Vercel Blob, Imgur, S3 — что есть)
2. Поменяй URL в HTML/CSS (Ctrl+F по `static.tildacdn.com`)

## Деплой

Самый простой путь — Vercel (бесплатно):

```bash
cd landings/tabata-2
npx vercel        # первый раз — настроит проект и зальёт
npx vercel --prod # production-деплой
```

Получишь URL вида `tabata-2-walk.vercel.app`. Привязать к поддомену `tabata.walk-walk.ru` — через DNS-настройку в Vercel + у регистратора домена.

Альтернативы: Netlify (drag-and-drop ZIP), Cloudflare Pages, GitHub Pages.
