# Инструкция для спеца Tilda — как поставить лендинг «Шагательная Табата 2.0»

## Файл для загрузки

**`tilda-embed.html`** — один файл, в нём весь HTML + CSS + JS уже склеены вместе.
Размер ~80 KB. Картинки лежат на внешних CDN (tildacdn.com и npopko55-cmd.github.io) — никаких ассетов в Tilda загружать не нужно.

---

## Шаги

### 1. Создать новую страницу

В нужном проекте Tilda → **«Создать новую страницу»** → дать имя «Шагательная Табата 2.0».

### 2. Отключить стандартные блоки шапки и подвала

Настройки страницы → **«Дополнительно»** → убрать галочки:
- ☐ Шапка сайта
- ☐ Футер сайта
- ☐ Шапка-меню (если используется на других страницах)

Нам не нужен лишний Tilda-header/footer — у нас свой сверху до низа.

### 3. Добавить один HTML-блок

В библиотеке блоков выбрать категорию **«Другое»** → блок **«T123 — HTML-код»**.
Это единственный блок на странице.

### 4. Вставить код из tilda-embed.html

В настройках T123 → **«Содержимое»**:
- Открыть `tilda-embed.html` в любом редакторе
- Выделить **ВСЁ** содержимое (Cmd+A / Ctrl+A)
- Скопировать (Cmd+C / Ctrl+C)
- Вставить в поле T123

### 5. Опубликовать

Кнопка **«Опубликовать»** в правом верхнем углу страницы. Подождать 30 секунд для активации.

## Что нужно проверить ПЕРЕД публикацией

### A. Ссылки на тарифы

В файле есть **3 ссылки на оплату**, которые надо заменить на реальные:

| Тариф | Текущая ссылка в коде | Нужно заменить на |
|---|---|---|
| Абонемент на 2 месяца | `href="/2-months"` | реальный URL оплаты для 2 месяцев |
| Абонемент на 6 месяцев | `href="/6-months"` | реальный URL оплаты для 6 месяцев |
| Абонемент на 2 года | `href="/all"` | реальный URL оплаты для 2 лет |

Никита пришлёт боевые ссылки на GetCourse / платёжку — их нужно подставить.

### B. Видео в блоке «Что такое Табата 2.0?»

Сейчас там **плашка-плейсхолдер** с иконкой "▶ Здесь будет видео".
В разметке это:
```html
<div class="about__video-frame about__video-frame--placeholder" id="kinescopeVideo">
  <div class="about__video-play" aria-label="Здесь будет видео">
    ...
  </div>
</div>
```

Когда придёт VIDEO_ID от Kinescope — заменить весь этот блок на:
```html
<iframe
  src="https://kinescope.io/embed/VIDEO_ID?autoplay=1&muted=1&loop=1"
  allow="autoplay; fullscreen; picture-in-picture"
  frameborder="0"
  allowfullscreen
  class="about__video-iframe"
  style="width:100%; height:100%; border:0; position:absolute; inset:0;">
</iframe>
```
(заменить `VIDEO_ID` на реальный идентификатор).

## Если что-то выглядит не так

- **Шрифты не загрузились** — проверить, что в коде есть `<link href="https://fonts.googleapis.com/...">`. Если Tilda Free-тариф блокирует внешние шрифты, можно убрать `font-family: 'Unbounded'` и оставить системные (запасной шрифт Arial уже прописан).
- **Картинки кейсов не отображаются** — они тянутся с `https://npopko55-cmd.github.io/tabata-2/assets/cases/`. Если этот URL перестанет работать (не должно, репо public), можно перезалить эти 10 webp-файлов в Tilda Media и заменить ссылки.
- **Жёлтая полоса вокруг «в 2 раза эффективнее»** не появилась — Tilda иногда стирает теги `<mark>`. Если так — поставить `<span class="claim-mark">` вместо `<mark>` и в CSS обновить селектор.

## Тех. детали (для проверяющего разработчика)

- Лендинг **семантический**: H1 / H2 / H3 / nav / section / footer / article.
- **Mobile-first адаптация**: 3 брейкпойнта 540 / 768 / 1024.
- **Sticky CTA снизу** на мобиле (768px и меньше) — кнопка «Записаться на Табату» по центру.
- **Marquee-карусели** для кейсов и отзывов — pause-on-hover, респектят `prefers-reduced-motion`.
- **Картинки кейсов в WebP** — 10× меньше JPEG, 556 KB всего.
- **Inline SVG** для лого и соц-иконок — нет лишних HTTP-запросов.
- **Preload hero-картинки** — улучшает LCP.
